# 시프트 관리 시스템 요건정의서

## 1. 프로젝트 개요

### 1.1 목적
10명 이하의 소규모 매장에서 아르바이트 스태프의 시프트 관리 및 출퇴근 관리를 효율화한다.

### 1.2 배경
- 현재 많은 소규모 매장에서는 종이 시프트표나 LINE 그룹으로 조율하는 것이 일반적
- 출퇴근 기록은 수기나 Excel로 관리하여 집계 실수가 발생하기 쉬움
- 기존 서비스는 기능 과다/고비용으로 소규모 매장에는 부적합

### 1.3 해결하고자 하는 과제
| 과제 | 본 시스템에서의 해결책 |
|------|----------------------|
| 시프트가 한눈에 안 보임 | 웹 캘린더로 시각화 |
| 출퇴근 기록이 애매함 | QR코드를 통한 정확한 타각 |
| 알바에게 별도 앱 설치시키기 어려움 | LINE 완결로 도입 장벽 제로 |

---

## 2. 대상 사용자

### 2.1 점장 (관리자)
- 소규모 매장의 오너 또는 점장
- 1명이 여러 매장을 관리하는 경우 있음
- IT 리터러시는 높지 않은 것으로 상정

### 2.2 아르바이트 스태프
- 학생, 프리터 등
- 스마트폰 (LINE 이용 가능) 소지
- 전용 앱 설치는 피하고 싶어함

|------|------|

## 8. 제약 사항 / 전제 조건

### 8.1 전제 조건
- 점장은 웹 브라우저를 이용할 수 있는 환경이 있을 것
- 매장에 QR코드 표시용 태블릿 (또는 PC) 설치가 가능할 것
- 아르바이트 스태프는 LINE을 이용하고 있을 것
- 아르바이트 스태프는 스마트폰에서 카메라 이용이 가능할 것

### 8.2 제약 사항
- 1매장당 스태프 수는 10명 이하를 상정
- 오프라인 환경에서의 타각은 불가 (통신 필수)
- LINE 이외의 SNS/앱에는 미대응

## 9. 용어 정의

| 용어 | 정의 |
|------|------|
| 점장 | 본 시스템의 관리자. 매장 정보, 스태프, 시프트를 관리함 |
| 스태프 | 아르바이트 종업원. LINE 경유로 출퇴근 타각을 수행함 |
| 시프트 | 스태프의 근무 예정. 날짜, 시작 시각, 종료 시각으로 구성 |
| 출퇴근 기록 | 스태프의 실제 근무 기록. 타각 시각을 기록 |
| 타각 | 출근 또는 퇴근 시각을 기록하는 행위 |
| 연동 코드 | 스태프의 LINE 계정과 본 시스템을 연결하기 위한 일회용 코드 |
| LIFF | LINE Front-end Framework. LINE 내에서 웹앱을 동작시키는 구조 |
